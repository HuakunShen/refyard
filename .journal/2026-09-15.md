# Project Journal — 2026-09-15

## 11:45:00 Web UI Modernization, shadcn Neutral Theme & Session Persistence

- **Core Decision/Topic**:
  - Overhaul the Refyard browser workbench UI with shadcn-svelte components, adopt authentic shadcn Neutral (pure grayscale/zinc) default styling across light and dark modes, fix layout squishing and responsive bounds, and ensure browser session credentials persist across tab closures and new windows.

- **Options Considered**:
  - *Theme Palette*:
    - Option A: Slate / cold blueish tones (oklch hues 250–260).
    - Option B: Pure shadcn Neutral / Zinc grayscale (chroma 0 in light and dark mode tokens).
    - *Choice*: Option B. The user explicitly requested removing cold blueish tones in favor of authentic shadcn neutral grays (`oklch(1 0 0)` canvas, `#e5e5e5` borders, `#18181b` charcoal primary in light; `#0a0a0a` background, `#171717` card, `#262626` border in dark). Preserved Blue as an opt-in accent preset.
  - *Credential Storage (`storage.ts`)*:
    - Option A: Keep bearer token in `sessionStorage` only. (Discarded: caused session loss whenever tabs close, preventing users from opening new tabs without re-pairing; clicking old links with spent tickets resulted in 401 error loops).
    - Option B: Store bearer token and `serviceInstanceId` in both `localStorage` and `sessionStorage`.
    - *Choice*: Option B. This allows session tokens (valid on the host for 8 hours) to be reused across tabs and browser restarts, while `negotiateSession` safely verifies `serviceInstanceId` against `/health` and wipes expired/restarted sessions.
  - *URL Parameter Lifecycle*:
    - Option A: Only strip `?pair=` from address bar on successful ticket exchange. (Discarded: left spent tickets in URL on failures or reloads, causing infinite failure loops).
    - Option B: Always strip `?pair=` via `window.history.replaceState` in `finally`, and ignore spent tickets if a valid session token is already active for this instance.
    - *Choice*: Option B.

- **Final Decision & Rationale**:
  - Clean neutral aesthetic aligns with modern workbench tools (e.g. shadcn, Linear, Raycast).
  - Persisting session credentials in `localStorage` alongside strict instance negotiation matches developer expectations: once paired, subsequent visits or new tabs connect automatically.
  - Providing clear instructions in `ConnectionPanel` (e.g. `p` + `Enter` in terminal to print a fresh ticket) eliminates friction when a ticket does need regeneration.
