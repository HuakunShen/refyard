# Refyard embedding facade fix round 4

## Timestamp

2026-09-23 09:10 Asia/Singapore

## Core decision/topic

Close the accepted Task 2 facade behavior gaps with executable facade contracts, while keeping durable journal records authoritative and preserving the existing transport-neutral service design.

## Options considered

- Keep `EmbeddedRefyard` uniquely owned and test submit-versus-close only through the internal queue. Rejected because the accepted behavior is a facade lifecycle contract and safe Rust cannot concurrently borrow for submit while consuming the same value for `close(self)`.
- Change `close(self)` to `close(&self)`. Rejected because it would change the accepted public signature and weaken the ownership signal.
- Share the existing `ApplicationService` behind `Arc` and make the facade handle cloneable. Chosen because it preserves `close(self)`, keeps one lifecycle/service instance, and allows a deterministic in-flight submit to race a close through two handles.
- Keep byte eviction as a direct `EventSink` unit test. Rejected because configured event bounds must be proved through `EmbeddedRefyard` and a real mutation lifecycle.

## Final decision and rationale

`EmbeddedRefyard` now holds `Arc<ApplicationService>` and implements `Clone`. Closing any handle shuts down the one shared engine; submissions already inside precondition reads either enqueue before closure or become durably cancelled after acceptance. The regression gates the precondition read, lets close win, and proves no `Accepted` record remains. The existing running-hook case proves close waits for a running effect's observed result.

All remaining gaps are covered at the facade boundary: configured stdout/stderr truncation, queue/repository limits, exact count/byte event gaps and retained envelopes, actor-scoped journal lookup, minted history/refs/diff/preview IDs, cross-repository snapshot/token refusal before Git mutation, stable recovery after client-ID reuse, and revoke/re-register. Matcher unit tests separately pin real local alias canonicalization and fail-closed distinct SSH paths.

## Key changes made

- Added deterministic Git wrappers and isolated repositories for output and close races.
- Added the B-before-A restart collision, exact event retention cases, and successful/cross-repository read/preview cases.
- Added Windows-only executable ACL assertions for current-owner plus SYSTEM protected full-control DACLs, reopen persistence, and fail-closed open when ACL enforcement is unavailable.
