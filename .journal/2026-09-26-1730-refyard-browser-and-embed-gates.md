# Refyard embedded Windows path and narrow browser gate

The Windows embedded facade CI failed two scripted SSH status tests even though a direct Git probe succeeded. The fixture passed a Windows 8.3 temporary directory while Git returned its long-name equivalent. String normalization could not establish that those paths named the same approved repository. The test helper now canonicalizes both fixture paths and only translates a remote when it resolves to the exact temporary repository. This keeps production target resolution and root approval unchanged. The exact combined branch revision `0369beb1` passed the embedded facade matrix on macOS, Ubuntu and Windows.

The 390 × 844 History regression was separate. A stacked layout kept the main region overflow hidden and let the History pane lose a bounded scrollport, so virtualized rows were not visible. The narrow main region now scrolls vertically while the History pane retains a 28rem viewport; wide layouts keep their existing grid/flex behavior. The test closes advanced Filters when inspecting results and reopens them before testing invalid SHA input. A compact responsive filter sheet is deferred as P2 in `docs/review-followups.md`, rather than claiming the current dense editor is ideal.

The offline E2E expected a removed wordmark. It now asserts the actual cached repository launcher and heading, while retaining connection-state and failed-read checks. A system-Chrome Playwright run passed all six focused History/offline tests, including the narrow filtered pagination case. The Web package type check and build had already passed after the layout change. This is real browser proof for these UI paths, not a claim that Xross has a native WebView or distributed service yet.

The alternative of accepting either short or long path by case-insensitive text prefix was rejected: it could quietly accept a sibling repository. Expanding the entire narrow History pane to fit results was also rejected after it rendered all 105 rows and defeated virtualization. Generated Paraglide churn from the local build was restored, and the temporary system-Chrome config was removed before the commit.
