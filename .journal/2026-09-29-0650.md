# Timestamp: 2026-09-29 06:50 SGT

## Core decision/topic

Repair Windows ACL drift on Refyard's durable authority files, not only on their parent
directories. The existing startup repair secured the state-root and journal directories but
then read the index, marker, records and workspace-root ledger through ordinary path opens.
The hosted Windows run demonstrated that this was insufficient: reopening failed while
reading `journal/index.json` with `Access denied`.

## Options considered

- Retry the file read or treat an unreadable index as missing. Rejected: this can hide or
  reset durable admission authority and would turn a permission failure into guessed state.
- Repair only `journal/index.json`. Rejected: the same ACL drift applies to the marker,
  operation records, workspace-root ledger, root marker and lock.
- Recursively change ACLs or loosen permissions. Rejected: this widens the repair scope and
  weakens the state privacy boundary.
- Repair each known authority file by handle before reading/opening it. Chosen: it keeps
  the repair list explicit and preserves fail-closed behavior for unexpected owners, types,
  reparse points and ACLs that cannot be verified.

## Final decision and rationale

The Windows host repairs a known state file's DACL using a no-follow security handle that
does not share delete access, verifies the current-user owner and exact protected
user/SYSTEM ACL, and reopens that same file object with `ReOpenFile` for reading or locking.
This avoids a path swap between ACL validation and data access. File ownership is not
rewritten. Newly published journal and workspace-root temporary files are secured before
atomic replacement. Directories retain their existing directory repair policy.

## Key changes made

- Added file-specific ACL repair and same-object read/lock opens in
  `crates/refyard-host/src/jobs/windows_acl.rs`.
- Routed journal marker/index/record reads, the state-root lock, and workspace-root
  ledger/marker reads through that repair path; secured temporary files before publish.
- Expanded the Windows embed regression to seed a durable record, inject NULL DACLs into
  all six authority-file categories, prove the injection with a readback oracle, reopen,
  and verify the exact private ACL is restored.
